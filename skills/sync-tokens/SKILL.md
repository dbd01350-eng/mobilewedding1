# /sync-tokens Skill

이 스킬은 코드베이스 내에 흩어져 있는 하드코딩된 색상 및 스타일 수치를 스캔하여, `css/style.css`의 `:root` 디자인 토큰으로 안전하게 동기화하고 코드 교체 대상 목록을 제시합니다.

## 🚀 실행 워크플로우

1. **에이전트 위임 (`token-guardian`)**:
   - `token-guardian` 서브 에이전트를 호출하여 코드 내 하드코딩 값을 스캔합니다.
2. **토큰 선언부 등록**:
   - 추출된 값들을 의미 있는 시맨틱 변수로 정리하여 `css/style.css`의 `:root` 섹션에만 등록합니다.
3. **교체 권고 보고서 제시**:
   - 일반 기능 코드는 덮어쓰지 않고, 사용자에게 `[파일명 / 라인 번호 / 현재 하드코딩 값 / 추천 토큰 변수명]` 목록을 보고하여 안전한 마이그레이션을 지원합니다.
